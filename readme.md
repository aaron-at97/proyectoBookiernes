# JOINT PROJECT - Bookiernes

## Introduction
This project is about developing a software for our
company "Bookiernes S.A". This company has decided to 
hire us because its sales had dropped exponentially 
due to the scarce relationship between the members 
of the company and their lack of communication. 
This problem has generated general discontent 
among writers and readers and our goal is to 
try to change it.

The company has decided to hire us because we 
work computerizing workflows and trying to avoid 
economic losses with the best structured idea and
workspace. Also, we need to centralize 
the workflow, and the communication between all the 
members of this company. 

## Prerequisites
In order to install all the dependencies 
needed to run the Django project:
```
pip install -r requirements.txt
```
Also, you will need to apply the migrations 
from the Django models by using:
```
python manage.py makemigrations
python manage.py migrate
```
Finally, you will be able to start the 
project locally using:
```
python manage.py runserver
```

Principios de Ejecución y ProgresiónRango de Repeticiones ($8\text{–}10$ vs $10\text{–}12$):En la prensa de pierna, el rango se sitúa deliberadamente en $8\text{–}10$ repeticiones pesadas para reclutar unidades motoras de fuerza pura sin vaciar el glucógeno local ni acumular lactato, cuidando la musculatura para la bicicleta.En el torso, el rango se fija en $10\text{–}12$ repeticiones para maximizar el tiempo bajo tensión ($TUT$), permitir paradas isométricas de $1\text{ segundo}$ y preservar la integridad articular en articulaciones como hombros y codos durante el déficit calórico.Criterio de Sobrecarga Progresiva:Cuando en las 3 series de un ejercicio alcances el tope de repeticiones ($12$ reps) con técnica limpia y sin ayuda externa, sube una placa de peso en la sesión siguiente.La intensidad diana debe situarse de forma constante en $RIR\text{ 1–2}$ (finalizar la serie con margen de únicamente $1$ o $2$ repeticiones antes del fallo concéntrico).Calentamiento y Series Efectivas:Las $3$ series indicadas en cada ejercicio corresponden a trabajo efectivo real.Antes del primer ejercicio de pierna y del primer empuje/tracción de torso, realiza $1$ o $2$ series de aproximación con el $50\%$ de la carga final para lubricar las cápsulas articulares sin generar fatiga previa.7.
